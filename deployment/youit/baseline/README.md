# Исторические серверные версии — НЕ ЗАПУСКАТЬ

Эти восемь файлов сохранены побайтно до исправления рисков. Они могут удалять
активные рабочие каталоги, каскадно удалять историю тестов или обнулять журналы.
Они нужны только для аудита и сравнения с SHA-256 в `server-patches.sha256.json`.
Актуальные реализации находятся в `maintenance/` и `systemd/`.
